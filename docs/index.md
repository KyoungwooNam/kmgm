# KMGM 문서

KMGM 문서의 시작 페이지입니다. 본문을 이 파일부터 채워 나가면 됩니다.

## 이 저장소에서 하는 일

- 문서는 `docs/` 폴더의 마크다운으로 작성합니다.
- 로컬에서 `mkdocs serve`로 미리 확인합니다.
- `main`에 푸시하면 GitHub Pages에 반영됩니다.

## 문서 목차

지금은 골격만 있습니다. 페이지를 추가한 뒤 아래 목록과 `mkdocs.yml`의 `nav`를 함께 갱신하세요.

- [문서 작성 가이드](writing.md) — 파일 위치, 문체, 새 페이지 추가 방법

## 다음에 채울 내용

프로젝트 소개, 설치·사용 방법, 참고 자료처럼 실제로 필요한 페이지를 정한 다음 `docs/`에 `.md` 파일을 추가하면 됩니다.
