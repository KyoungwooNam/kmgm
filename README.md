# KMGM 홀덤펍 이벤트

홀덤펍 이벤트를 화면에 띄우고, 관리자가 내용과 참여자를 기록하는 페이지입니다.

- 사이트: https://kyoungwoonam.github.io/kmgm/
- 저장소: https://github.com/KyoungwooNam/kmgm

지금은 세 가지 이벤트가 있습니다.

| 이벤트 | 규칙 |
| --- | --- |
| 3×3 빙고 | 칸 내용을 맞추면 표시, 한 줄이면 빙고 |
| 10~A 포켓 | 10·J·Q·K·A 포켓으로 각각 승리하면 당첨 |
| 데일리 출석 | 월~일 출석을 기록하고, 일주일을 채우면 만근 |

기록은 이 페이지를 연 **브라우저**에 저장됩니다. 펍 태블릿이나 전광판으로 쓰는 기기에서 관리하면 됩니다.

## 관리자

헤더의 **관리자**로 들어갑니다. 초기 비밀번호는 `kmgm` 입니다. 들어간 뒤 바꿀 수 있습니다.

관리 모드에서는 다음을 할 수 있습니다.

- 빙고 칸 문구 수정
- 참여자 이름 등록·삭제
- 빙고 칸 달성 / 포켓 승리 / 출석 표시
- 참여자 명단만 초기화

## 로컬에서 보기

```bash
python3 -m http.server 8000 --directory docs
```

브라우저에서 http://127.0.0.1:8000 을 엽니다.
